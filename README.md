# vhodges/homebrew-tap

Personal [Homebrew](https://brew.sh) tap for [Manyhands](https://github.com/vhodges/manyhands),
local-first, Git-backed project management and documentation.

## Install

```sh
brew tap --trust vhodges/tap
brew install --cask vhodges/tap/manyhands
```

Homebrew has to trust a third-party tap before it will audit its casks, so tap
it with `--trust` first. Read the cask before you do; it is a single short file.

This installs `Manyhands.app` into your applications directory and links the
`manyhands-cli` command onto your `PATH`.

## Requirements and caveats

- **Apple Silicon only.** The cask has no Intel build.
- **Not notarized.** Builds are ad-hoc signed, not Developer ID signed or
  notarized, so macOS may refuse to open the app the first time. Use macOS's
  normal approval flow (System Settings, Privacy & Security) if you trust it.
  The cask does not remove quarantine attributes.
- **Keep the CLI where Homebrew puts it.** `manyhands-cli` is a symlink into the
  Caskroom, next to the libraries and licence notices it loads. Don't copy the
  executable elsewhere on its own.
- **Uninstall keeps your data.** `brew uninstall --cask manyhands` leaves
  settings, credentials, repositories and Manyhands data in place.

Other platforms (Linux, Windows) are served by archives and installers on the
[Manyhands releases page](https://github.com/vhodges/manyhands/releases).

## Layout

```text
Casks/m/manyhands.rb   # generated by the Manyhands Release workflow
```

## Maintaining the cask

`manyhands.rb` is generated, not hand-written. Each Manyhands release run
produces a version- and checksum-specific cask as a release asset. The tap is
updated only after the release is **published**, so the cask never points at
draft-only downloads.

1. Publish the GitHub release (prereleases such as `v0.2.0-rc.1` are fine for
   testing, but don't leave one as the tap's latest by accident).
2. Download `manyhands.rb`, `SHA256SUMS` and the macOS archive from the
   release, and check them against `SHA256SUMS`.
3. Copy `manyhands.rb` to `Casks/m/manyhands.rb`.
4. On an Apple Silicon Mac, with `TAP=vhodges/tap`:

   ```sh
   brew tap --trust "$TAP"
   brew style --cask Casks/m/manyhands.rb
   brew audit --cask --online "$TAP/manyhands"
   brew install --cask "$TAP/manyhands"
   env -u DYLD_LIBRARY_PATH -u DYLD_FALLBACK_LIBRARY_PATH manyhands-cli --help
   open -a Manyhands
   brew uninstall --cask "$TAP/manyhands"
   ```

   Running the CLI through Homebrew's symlink checks that its relative library
   paths load. Confirm the app's notices are readable and that uninstall
   preserves user data.
5. Commit and push.

See Manyhands' [release packaging guide](https://github.com/vhodges/manyhands/blob/main/packaging/README.md)
for how the cask is generated.
